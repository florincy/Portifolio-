# Portfólio — Simone Florincy

Portfólio estático de Data Science, Business Intelligence e soluções aplicadas a operações offshore.

## Publicação no GitHub Pages

1. Crie um repositório e envie todo o conteúdo desta pasta para a branch `main`.
2. Em **Settings → Pages**, selecione **GitHub Actions** como fonte de publicação.
3. O fluxo incluído em `.github/workflows/pages.yml` publicará o site automaticamente.

O projeto usa apenas HTML e CSS, não exige instalação e funciona corretamente em endereços de projeto como `usuario.github.io/repositorio/`.
